# Plate

**Status:** wip · not audited. Work in progress: a gated security token is issued to a cleared wallet and settles against cash.

Plate is a security token with a compliance check. A wallet receives the token when it passes the check, and a transfer of the token settles against a cash balance on-chain. The check is the same kind of clearance [Lien](/v1/lien/) uses for who may borrow.
